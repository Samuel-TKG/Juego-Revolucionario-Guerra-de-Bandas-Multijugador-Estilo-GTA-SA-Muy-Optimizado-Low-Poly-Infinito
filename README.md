# Juego-Revolucionario-Guerra-de-Bandas-Multijugador-Estilo-GTA-SA-Muy-Optimizado-Low-Poly-Infinito
1000 jugadores online estilo GTA San Andreas. 5 ciudades, autopista de 12 carriles, tráfico masivo low-poly, bandas infinitas. Únete a una banda, crea una o sé policía dando orden a la ciudad y controlando todos los territorios Conduce Vehículos, guerra infinita, ligero, entretenido y realista para PC y Android y iOS.
